Hi! This is a demo of my blue prince wiki. The code I am using to host my obsidian page is from the `feat/bases` branch of [Quartz](https://quartz.jzhao.xyz/), which is a way to freely host Obsidian wikis.

This wiki is glitchy and some properties are not visible, which is why I recommend downloading the Vault [here](https://github.com/MarkovChainmail/blue-prince-obsidian) instead!

The most interesting parts of this wiki are the Timeline (which does not sort by date properly, but is sorted properly in Obsidian) and the web of articles which can be viewed by clicking on the icon to the right.
